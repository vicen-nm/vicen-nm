## 📂 Work

**ConditionReports.com** — *AlienCat Software*
Full-stack features for a vehicle inspection platform serving thousands of users and auction workflows. Built an internal ASP.NET Core app from greenfield to production, engineered billing and OBDII data storage on Azure Blob Storage, and extended damage report coverage across dealer and auction systems.

**FuxionMix** — *AlienCat Software*
AI-powered visual ads platform built from scratch. Integrated OpenAI APIs for automated copy generation, built a custom video player with real-time overlays and animations, and engineered an async FFmpeg pipeline for rendering video ads without blocking the UI. Yes, I also built the video player.

**PhoneIQ** — *AlienCat Software*
Resolved a critical outbound calling regression across a multi-tenant VoIP platform by tracing a Caller ID misrouting bug nobody else could pin down. Also kept services alive during a live Equinix → AWS cloud migration by diagnosing stale proxy configs mid-incident.
